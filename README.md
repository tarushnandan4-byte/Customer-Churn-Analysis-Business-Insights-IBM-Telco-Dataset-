# 📊 Customer Churn Analysis & Business Insights (IBM Telco Dataset)

An end-to-end Exploratory Data Analysis (EDA) project investigating customer churn drivers, financial sensitivities, and qualitative exit reasons for a telecommunications provider.

## 🚀 Project Overview
In the subscription-based tech and telecom sectors, retaining customers is significantly more cost-effective than acquiring new ones. This project analyzes the IBM Telco Churn dataset to uncover *who* is leaving, *why* they are leaving, and *what* the business can do about it.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Environment:** Jupyter Notebook
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## 📈 Key Visualizations & Findings
1. **Contract Type Risk:** Visualized how month-to-month agreements spike churn to ~43% while 2-year contracts secure near-total retention.
   ![Customer Churn Distribution by Contract Type](contract_churn.png)
3. **Payment Method Friction:** Proved that electronic checks create massive drop-off rates compared to seamless automatic billing.
   ![Customer Churn Distribution by Payment Method](payment_churn.png)
5. **Financial Impact:** Highlighted how higher monthly charges correlate with increased customer sensitivity and defection.

## 💡 Business Recommendations
* Transition month-to-month users via promotional annual discounts.
* Provide automated payment incentives to cut down electronic check friction.
* Retrain support staff to address the leading qualitative complaint: support attitude.
